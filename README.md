# Student Planner SaaS — StudyFlow

A responsive student planner starter project for tracking assignments and organizing study sessions. Built with HTML, CSS, and vanilla JavaScript, so it runs locally without a build step.

## Features

- Add, complete, and delete tasks
- Label tasks by priority
- Create and remove study sessions
- Responsive dashboard for desktop and mobile
- Saves tasks and sessions in the browser with `localStorage`
- No API keys or backend setup required for the starter version

## Run locally

1. Download and extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Start adding tasks and study sessions.

Optional: use the VS Code Live Server extension for local development.
